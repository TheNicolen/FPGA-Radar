## Cómo añadir avances

1. Duplicar [`TEMPLATE.md`](TEMPLATE.md) con nombre `AAAA-MM-DD-tema.md`.
2. Indicar etapa, cambios, evidencias y riesgos pendientes.
3. Adjuntar gráficos y archivos relevantes en `experiments/` o enlazar a su ubicación.
4. Distinguir claramente cálculos, simulaciones y resultados medidos.
5. Añadir el nuevo documento a este índice.
