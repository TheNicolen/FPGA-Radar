# ADR-0004 — Privacidad y evidencia verificable

- Fecha: 2026-11-14
- Estado: Aceptado por instrucción del responsable

## Contexto

El proyecto se documentará en GitHub privado; requiere distinguir teoría de validación física.

## Decisión

Mantener el repositorio privado, sin cambios de visibilidad. Versionar fuentes, configuraciones y resúmenes; preservar datos grandes en almacenamiento privado con hashes. Clasificar afirmaciones según la [política de evidencia](../00-metodologia/evidencia.md).

## Alternativas

Repositorio público o resultados sin datos trazables: descartados para el alcance actual.

## Consecuencias

Las colaboraciones requieren acceso autorizado. La privacidad no reemplaza control de credenciales ni consentimiento sobre datos. Una entrega local no prueba que el remoto esté sincronizado o privado.

## Revisión

Cualquier cambio de privacidad requiere una nueva instrucción explícita del propietario. No asumir autorización a partir del material inicial.

## Adenda sobre visibilidad

El propietario indicó mantener el repositorio público. Esta instrucción reemplaza la decisión histórica de privacidad para GitHub. Sigue vigente la política de evidencia. La visibilidad se mantiene según la configuración actual.
